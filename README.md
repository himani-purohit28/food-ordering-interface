🍽️ Food Ordering Interface

A modern, responsive food ordering interface designed to make browsing and selecting food simple, intuitive, and visually engaging.

The interface brings together pizzas, burgers, drinks, and desserts in a clean food-focused experience with interactive cart functionality.

✨ Features

- 🍕 Browse food across multiple categories
- 🛒 Add items to the shopping cart
- 💰 Automatically calculate the cart total
- 📱 Responsive layout for desktop and mobile screens
- 🎨 Clean and modern visual design
- ✨ Interactive hover effects and basic animations
- 🧭 Simple and intuitive navigation

🛠️ Built With

- HTML5 — Structure and content
- CSS3 — Styling, responsive design, animations and layout
- JavaScript — Cart functionality and user interactions

🎯 Project Focus

This project focuses on creating a frontend experience that is:

- User-friendly — easy to browse and interact with
- Responsive — designed to adapt across different screen sizes
- Visually consistent — using a cohesive color palette and component styling
- Interactive — providing immediate feedback through cart interactions and UI effects

🚀 Getting Started

Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open "index.html".
4. Launch it using a local development server such as Live Server.
